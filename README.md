## Project Overview
This repository contains a working prototype of an educational data warehouse designed to analyze key university metrics. The system utilizes an ETL pipeline to extract publicly available academic datasets, transform them into a unified schema, and load them into a relational SQL database. A live OLAP dashboard provides interactive business intelligence insights.

### Scope Covered:
1. **Student Performance:** Average scores and grade distributions.
2. **Attendance:** Tracking attendance percentages and critical alerts.
3. **Placement Statistics:** Salary distributions and placement ratios.
4. **Faculty Workload:** Weekly workload analysis derived from years of service and rank.

## Technology Stack

* **Database:** SQLite (Relational Database)
